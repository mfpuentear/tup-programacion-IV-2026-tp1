# Ejercicio 3 - API de Tareas
Se desarrollo una API para administrar tareas y su estado de avance.
Cada tarea tiene un nombre y un estado (true = completada, false = pendiente).
la informacion se guarda en un arreglo interno

 Decisiones de diseño
validacion para que cada tarea tenga nombre y estado.
no se permiten tareas repetidas.
se agrega un filtro con query params para diferenciar tareas completadas de pendientes.
